# PCB Offline Android

Project Android WebView untuk aplikasi PCB yang berjalan offline.

## Build APK tanpa komputer

Project ini sudah dilengkapi GitHub Actions. Upload seluruh isi project ke repository GitHub, lalu buka tab **Actions** dan jalankan workflow **Build APK**. APK debug akan tersedia sebagai artifact bernama **PCB-Offline-APK**.

GitHub Actions menyimpan hasil build sebagai workflow artifact yang dapat diunduh dari halaman run workflow.
